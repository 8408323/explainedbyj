Why a page instead of localhost

TikTok only redirects to an HTTPS URL on a verified domain, so the usual loopback-server trick used for the YouTube flow is not available. The code arrives as a query parameter; this page just makes it readable instead of leaving you to dig it out of the address bar.

The code is short-lived and single-use. Nothing on this page is stored or sent anywhere — it is a static file, and the value never leaves your browser.
