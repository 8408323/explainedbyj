ExplainedByJ is run by one person. This policy covers this website and the private publishing tool used to upload videos to the channel's own social media accounts.

What this site collects

Nothing. These pages are static files served by GitHub Pages. There are no accounts, no cookies set by us, no analytics and no tracking scripts. GitHub may log requests as part of operating its hosting; see the GitHub Privacy Statement.

The publishing tool

The channel uses a private, self-hosted tool to upload its own videos to its own accounts on YouTube, Instagram, Facebook and TikTok. It is not offered to anyone else and has no other users.

  • It acts only on accounts owned by the channel operator.
  • It reads and writes nothing belonging to any other person.
  • Access tokens are stored on the operator's own machine and are never shared or transmitted anywhere except to the platform they belong to.
  • It does not collect, store, sell or share personal data of any kind.

Contacting the channel

If you email explainedbyj@gmail.com, that message is kept only so it can be replied to. It is not added to any mailing list and is not shared.

Comments on social platforms

Comments and messages left on YouTube, Instagram, Facebook or TikTok are held by those platforms under their own privacy policies, not by this site.

Your rights

The operator is in Sweden and subject to the GDPR. Because no personal data is collected here, there is normally nothing to access, correct or erase — but if you have emailed and want that correspondence deleted, ask at the address above and it will be.

Changes

If this policy changes, the date at the top changes with it.
