# explainedbyj

Public site for the **ExplainedByJ** channel. Two jobs, both practical:

1. **Policies.** TikTok's developer app review requires a public Terms of Service
   URL and Privacy Policy URL, and Meta's app settings ask for the same pair.
2. **Publishing assets.** Instagram's Content Publishing API does not accept a
   file upload — it fetches the video from a public HTTPS URL. `media/` holds the
   renders being published so Meta has somewhere to fetch them from.

Served by GitHub Pages from `main`.
